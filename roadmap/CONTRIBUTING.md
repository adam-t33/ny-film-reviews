# Contributing to NY Film Reviews

## How I Work
- Each feature gets its own branch (`feature/review-template`)
- PRs are small and focused
- Tests pass before requesting review
- You merge when satisfied

## My PR Workflow
1. Create feature branch
2. Implement changes
3. Test locally
4. Open PR with description
5. Request review
6. Iterate based on feedback
7. Merge on approval

## Code Standards
- Clean, readable code
- Comments for complex logic
- Mobile-first CSS
- Semantic HTML

## Content Guidelines
- Reviews should be personal but informative
- Include spoiler warnings
- Credit image sources
- Follow markdown formatting

## Feature Requests
Add to GitHub Issues or Discord me directly!
