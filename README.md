# NY Film Reviews

A collection of film reviews curated for New York cinema enthusiasts.

## About

This repository contains reviews of films currently showing in New York theaters, as well as retrospectives of classic NYC-centric cinema.

## Structure

- `/reviews/ - Individual film reviews
* `/watchlists/ - Monthly curated watchlists
* `/ratings/ - Aggregated rating system

## Contributing

Feel free to add your own reviews via pull request.
